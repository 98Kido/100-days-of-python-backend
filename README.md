# 100 Days of Python – Backend Development 🐍⚙️

This repository documents my 100 Days of Coding journey focused on
Python backend development.

## Focus Areas
- Python fundamentals and clean code
- Backend frameworks (Flask / FastAPI)
- RESTful APIs
- Databases (SQLite, PostgreSQL)
- Authentication and authorization
- Environment variables and configuration
- Basic deployment concepts

## Goal
To build a strong foundation as a Python backend developer by creating
small, practical projects and APIs while improving problem‑solving
and software engineering skills.

## Outcome
By the end of the challenge, this repository will contain multiple
backend projects demonstrating real‑world Python development skills.
